This blog has a new look. Yes, I have converted it from the **Golang** with **HTMX** into [Hugo](https://gohugo.io/).

While doing this, I'm absolutely stuned by how fast I can build this blog with **Hugo**. It has
everything that I need with so many themes plugin. My old version was my attempt to reinvent the
wheel to build a blog. It got me thinking, why do I have to write code anymore with a vast libraries
and frameworks that support us to build almost everything, especially with the AI surge at the
moment?

Well, I don't think that my investment on my old project is a total waste of time (by the way, you
can find the source code in [here](https://github.com/saldyy/a-blog-by-saldyy), please excuse for
that mess of the code 😅). The whole reason I chose the tech was that I want to experiment the power of HTMX
in terms of implementing a normal website. My approach is quite similar with **Hugo**, we both use Front matter to
display the metadata of the post, both use markdown to render HTML. When finding my way to make it
works, I learnt quite a lots about HTMX, how it redirected and rendering part of the website. I even
used the same markdown parser [goldmark](https://github.com/yuin/goldmark) with **Hugo** as well
(it's very powerfull, I highly recommend it). I was on the right track to build my own version of
**Hugo**, but I can never finish it to that level due to the shortage of time and man power.

One thing that I dislike most from my old project is hosting. The project was packaged into a
**Docker** image and I haven't found any good platform with free tier to host it. I tried
[Railway](https://railway.com/) and it works really well until the free trial runs out. 

After all, it all comes down to choose the right tools for the right job. After explore everything
that I want with **HTMX**, I just want to have a tools to write all of my stuff and hosting it free
of charges (speaking of which, I'm currently working on doing a homelab, maybe that's the best way,
will write my updates about it). Then **Hugo** is my best option. I don't think I need to talk too much about
how powerful it is, hosting it also very easy with a versality of supports on multiple platform.

Point taken here for me: just do anything that you want, even if it is reinvent the wheel. The
problem you met is also the same problem that the previous person met, from that you can learn and
apply it to your arsenal. No effort is meaningless.
